## Create the file

Place a new file under:

```txt
content/blog/<category>/<slug>.md
```

## Add frontmatter

Use `title`, `description`, `author`, and `date` so UI surfaces stay clean.

## Add headings

Use `##` and `###` headings to feed the right-side progress TOC automatically.
